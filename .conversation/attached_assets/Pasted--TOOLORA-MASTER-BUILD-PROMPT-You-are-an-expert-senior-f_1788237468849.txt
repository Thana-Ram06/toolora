# TOOLORA — MASTER BUILD PROMPT

You are an expert senior full-stack developer, UI/UX designer, and product engineer.

Build a complete, production-ready website called **Toolora** — a free, modern, all-in-one online tools platform.

## 1. CORE PRODUCT

Toolora provides a large collection of useful online tools for everyday users, creators, students, designers, and developers.

Primary tagline:

**"Simple tools. Zero hassle."**

Secondary description:

**"Free online tools for everyday things — compress, convert, calculate, generate, format, and more."**

The website must feel like a real polished SaaS/product website, NOT like a generic developer dashboard or a basic collection of HTML tools.

Every tool should be easy to discover, easy to use, fast, and visually consistent.

---

# 2. VERY IMPORTANT — VERCEL COMPATIBILITY

I will deploy this project on **Vercel**.

Therefore:

### STRICT REQUIREMENT:

Build the entire project to be **fully Vercel-friendly from the beginning**.

Do NOT use anything that will cause deployment problems on Vercel.

Prefer a modern frontend architecture such as:

* React
* Next.js with App Router
* TypeScript
* Tailwind CSS

Use Next.js if it provides the cleanest Vercel deployment.

### Avoid:

* Replit-specific runtime dependencies
* Replit databases
* Replit authentication
* Replit-only APIs
* Long-running server processes
* Local filesystem persistence
* Anything that requires a permanently running backend
* Hardcoded localhost URLs
* Environment-specific hacks
* Features that only work inside Replit

The final project must be deployable to Vercel using the standard build process.

Use client-side/browser APIs wherever practical.

For file-processing tools, process files locally in the browser whenever technically possible so that files do not need to be uploaded to a server.
